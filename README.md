# Second Growth

A rewilding tycoon game shown as an isometric 3D diorama, with seven regional maps: the Pacific Northwest, Amazon, Serengeti, Atlanta, Nicaragua, a tropical reef, and Sumatra. You don't buy animals or upgrades. You shape water and soil, brush in native plants, pull invasives, and tear out the old farm. Wildlife then follows its own rules: it wanders in from the surrounding forest, river and farms when there's room, raises young, hunts, and moves on when there isn't enough.

## Running it

There's no build step. The game is plain JavaScript modules plus a vendored copy of [three.js](https://threejs.org) (MIT, in `vendor/three/`), so it just needs a local web server:

```bash
python3 -m http.server 8347
```

Then open http://localhost:8347. The game autosaves on this device every 30 seconds, every in-game month, and when the tab becomes hidden. No account or save server is needed.

Browser saves use IndexedDB with compact binary map arrays, an integrity check, and the latest snapshot plus two previous distinct versions per map. Existing localStorage saves migrate automatically and are removed only after the database commit succeeds. Continue automatically tries a backup if the newest snapshot is damaged or incompatible. Menu → Restore an earlier save also lets players roll back inside the game, while keeping their current progress as a backup. Starting a new farm clears that map's older versions after the existing replacement confirmation.

The Saved / Saving / Save failed indicator reports completed writes. Autosave also protects paused games, and map switches wait for the current save before reloading. The game requests persistent browser storage when play begins; browsers may grant or deny it. Saves remain tied to this site's browser profile and device, and clearing site data removes them. If IndexedDB is unavailable, saving falls back to the original localStorage format with its smaller capacity and no rotating backups. Autosave can still be disabled in Settings; manual Save game remains available.

Run `node tools/browser-save-check.mjs` for real IndexedDB migration, binary round trips on all seven maps, backup rotation and recovery, failed writes, queued saves, persistence handling, and the actual Continue, recovery and map-switch UI. It launches Google Chrome in an isolated temporary profile and serves the game on a temporary localhost port; set `CHROME_PATH` for another Chromium installation. `tools/browser-save-check.html` runs storage checks in a temporary database with in-memory legacy storage, leaving existing farms untouched.

## Release checks and shared rules

Use Node 22 or newer and Google Chrome (or set `CHROME_PATH` to a Chromium executable). Run one command before releasing:

```bash
node tools/check-release.mjs
```

`--headless` runs the simulation, model, scale and interaction checks without a browser. `--browser` runs real saving, touch controls, plant rendering, visual references and gameplay performance. Each script runs in its own process so map registries and random state cannot leak between checks. Any failed script blocks the release. Per-script logs, JSON reports and the image review page are in the ignored `tools/release-output/` directory. Browser checks use an isolated temporary profile and localhost server.

The new `consistency-check.mjs` exercises all seven maps at all three difficulties: terrain editing and refunds, seasonal ecology, population bookkeeping, and save/restore after changing maps. All 218 regional adult appearances and variants must have valid geometry; the size audit checks shared scaling and relative proportions. Existing focused checks protect hunting, herds, birds, climbing, water, plant growth and rendering. A new dynamic needs a focused test of its intended outcome plus interactions with the systems it changes, especially pause, removal of habitat, undo and persistence. Prefer reproducing an actual bug over tests that merely repeat implementation details.

`release-browser-check.mjs` compares 21 tracked visual references: each map's landscape in Fast and Full detail, plus every adult animal appearance in production field-guide portraits. Open `tools/release-output/review.html` after a run to compare reference, current and difference images. A scene that looks different from its reference is reported for review (a warning on the GitHub run), not a failure, so an intentional look change doesn't hold up a release; errors, broken edits and draw budgets still fail. A gameplay measurement that times out on CI's software renderer gets one retry. Portraits use inspection framing; their image sizes do not represent relative animal sizes. The live world galleries also render adults, variants and juveniles for geometry budgets and edit/restore checks. Images hold camera, viewport, pixel ratio, lighting time, weather and random seeds fixed. Simulation and live animation are checked separately.

The gameplay measurements run the actual `main.js` loop, including input updates, 3D rendering, decorative overlays and DOM interface work. They cover a restored landscape, a 96-animal herd and repeated planting while panning. Simulated time is fixed per frame, with 12 warm-up frames and 60 measured frames. GPU completion is included. Frame-work timings measure the live loop; frame-interval timings also show browser painting and scheduling delays. CI uses software graphics: these numbers detect regressions and stalls, and are not a promise of phone or laptop frame rates. Timing regressions compare matching CPU, browser, GPU and benchmark revisions; draw-call, triangle and resource budgets apply on every machine. A short play session on a real phone remains part of release review.

For an intentional visual change, capture candidate references explicitly:

```bash
node tools/release-browser-check.mjs --update-visuals
```

Inspect the review page and the changed images, then commit the approved `tools/release-baselines/` files with the code. Reference updates are refused in CI and are saved only after all scenes and performance checks succeed. Normal checks never rewrite references. Historical detail/polish/size comparisons against ignored snapshots require `--historical-baseline`; those snapshots describe earlier passes and may no longer match later intentional changes.

The GitHub checks workflow runs the headless simulation checks on pull requests; the slower browser checks run when it is started by hand. The itch.io publishing workflow waits for both simulation and browser checks on the exact commit it packages. Manual packaging with `tools/build-itch.sh` also runs all checks and requires committed release files so it cannot test one version and package another.

Keep these shared contracts when adding features:

- **Gameplay:** time, difficulty, costs, habitat capacity and saved state belong in the simulation and data modules. Every map uses the shared tool, undo and persistence paths. Player input and scripted plans use `ToolActions` in `js/tool-actions.js`: `begin` → `paint` → `end` for a gesture, or `apply` for explicit tiles. It owns campaign eligibility, prices, duplicate suppression, payment, statistics, optional Undo recording, completion hints and environment refresh. `tools.js` defines the tile mutations; controls and the renderer handle gestures and drawing. Low-level tests may call a mutation directly to isolate it. Map hooks express regional ecology; common mechanics should have one implementation.
- **Movement:** hunting, groups, landing and explanations use `js/sim/animal-terrain.js`. Put exceptions in that shared policy instead of redefining barriers inside each behaviour.
- **Art:** reuse `render3d` models, materials, animation parts, scale helpers and regional palettes. Animals share soft model forms, readable silhouettes, coherent proportions and ground/water/canopy contact. Each map keeps its own climate, flora and colour palette within that common treatment. Inspect both gameplay scale and field-guide portraits, including young and adult variants.
- **Rendering:** read simulation state and use the existing dirty/rebuild paths for edits and restores. Decorative effects must not silently change habitat or gameplay. Record detail level, resolution and shadows with performance results so automatic quality changes cannot conceal extra work.
- **Experiments:** keep standalone simulations and review tools under `tools/` until they are deliberately integrated through these shared systems. Production releases package only game files.

## Controls

- **Campaign or Free Play.** The campaign walks you through eight chapters on the same farm (fields, water, opening the gates, shading the creek, wildlife homes, fire and flood, visitors, reintroductions). Each chapter has three goals and unlocks the next set of tools; wildfires and floods begin in Chapter 6. Free Play has every tool from the start.
- **Campaign help.** Expand the chapter tracker and choose **Need help? Where and how** to revisit the action and location instructions. Visitor chapters also show the next step: build **Visitors → Trailhead parking** (the trailhead itself) on a dry 2 × 2 patch beside a road inside the property, connect a trail starting within two tiles of the lot, then extend it to 40 connected tiles. Visitors and ratings update at month end. Run `node tools/campaign-help-check.mjs` to check visitor guidance across Hollis, Amazon and Serengeti campaigns.
- Pick a tool on the left, then click and drag to brush it. `[` and `]` change the brush size, and each tool group remembers the size you last used.
- Right-drag or `WASD` / arrow keys to pan, scroll wheel or `+`/`-` to zoom, `Q`/`E` to rotate the view.
- `Space` pauses, `1`–`3` set the speed. `T` sees through trees, `H` toggles the habitat overlay, `G` opens the field guide, `Tab` hides the side panels.
- Panels collapse with their `−` button, and fade out while you paint.
- Brush edits repaint their ground patch on the next frame and give the edited plant region priority over queued growth. Daily and seasonal changes retain their slower refresh cadence and one-region-per-frame budget. Run `node tools/brush-render-check.mjs` for continuous strokes, region crossings and seasonal queues; `node tools/tool-actions-browser-check.mjs` checks the first visible frame during actual mouse and phone drags.
- Plant visibility uses a small margin around the viewport so short pans reuse their instance buffers. Zoom, rotation and detail changes refresh visibility immediately. Regional edits update the affected models and source selections; unchanged models and offscreen source edits retain their visible buffers. Model bounds keep opaque draw ordering stable across cached pans. `node tools/plant-cache-browser-check.mjs` checks cached pans and edits against precise batching and complete-source reference images on every map. `node tools/plant-cache-benchmark.mjs --stage=pan` and `--stage=regional` measure each optimization separately with alternating runs and GPU completion; these local CPU-throttled results do not represent real phone FPS.
- Use **Inspect** to click a tile or an animal. The **Overlay** menu shows moisture, soil, sunlight, fish passage, or where a given species could live. In the field guide, the pin on any species that lives here jumps the camera to one of them and follows it.
- **Wildlife behavior:** Animals take short feeding pauses at actual grass, browse, canopy leaves, seasonal fruit, seeds, insects or nectar. Reef feeders seek seagrass, sponges, algae or sediment, and cleaner wrasse tend nearby clients at established stations. Waders stalk and strike from shore rather than dive; spoonbills sweep their bills. Fish escape through passable water, coyotes recruit at most one hunting partner, male horn-bearing mammals spar, and male giraffes neck alongside one another. A failed hunt never counts as a meal. Feeding stops when food is removed or danger intervenes, and transient meals revalidate after loading. Population capacities and strict caps still apply. The guild audit and primary sources for all 200 regional entries are in `tools/animal-behavior-audit.json`; run `node tools/animal-behavior-audit.mjs` to refresh the inventory and `node tools/animal-behavior-check.mjs` to test outcomes.
- **New wildlife:** Atlanta supports up to two river otters and two coyotes; Serengeti supports small resident herds of up to eight topi and six Coke’s hartebeest. The reef supports up to ten black sea cucumbers and eight collector sea urchins, which stay on the seabed; urchins graze algae on their own tile. These are strict limits for arrivals and offspring, including animals still leaving the map. Available habitat and prey can reduce populations further. New species are appended so existing saves retain their animal identities. Run `node tools/wildlife-additions-check.mjs` for recruitment, birth, habitat-loss, ten-year population and save checks.
- **Wildlife diagnostics:** the field guide and animal inspector explain current capacity, missing habitat resources, prey or herd dependence, disturbance, entry barriers, seasonal absence and the time needed to discover new habitat. The guide refreshes at monthly checks. Salmon use their creek spawning threshold and October run; migrating Serengeti herds use the north-edge migration fence rule. Natural arrivals remain chance-based.
- **Beaver dams** stand while beavers tend them. A dam no beaver has visited for half a year usually washes out within the year after, and Demolish pulls one apart at once (beavers still nearby may build another). Either way the pond drains, the creek runs through again, and the flooded ground is left as damp, rich soil or marsh. Run `node tools/beaver-dam-check.mjs`.
- **Salmon and bears:** the coho run arrives at the mouth of a connected creek: 5 to 9 strays the first years, growing with fish born here up to one and a half times what the creek's spawning habitat supports. Bears come down to the bank, swipe at any salmon within reach and eat their catch there; a fed bear rests for about a week before fishing again, so most of the run survives to spawn. Run `node tools/salmon-bear-check.mjs`.
- **On a phone or tablet:** the thumbstick at the bottom left moves the map (two fingers do too), pinch to zoom, and the arrow buttons rotate the view. Pick a tool and drag one finger to brush it, or tap to place things or inspect; with Inspect picked, one finger drags the map (flick it and it glides). Push the stick mid-stroke and the brush keeps painting as the land slides under your finger. Touching the map folds the tool panel down to the tool in hand; tap its group to open it again. Phones play in landscape (portrait shows a "turn your phone" screen); full screen or Add to Home Screen gives the most room.
- **Graphics on phones:** touch screens start on the Fast detail setting (simpler plant models until you zoom right in, half the grass tufts, a smaller shadow map, and the ground and plants refreshing at a gentler pace), and the view adjusts its own resolution to hold a steady frame rate, turning shadows off for the session if even the lowest resolution can't keep up.
- The gear button opens **Settings**: audio (lo-fi music and nature sounds, each with a volume), gameplay (difficulty, autosave, pausing on wildfires and floods, notification level), graphics, controls and privacy. The speaker button or `M` mutes everything.
- **Difficulty:** Relaxed, Standard or Challenging. It scales starting money, grants, what work costs, how often fire and flood come, and how hard invasive seeds press in from the neighbours. Pick it for a new game, or change it any time in Settings.
- **Challenging ecology:** deer and other browsers can kill young trees on their tile or directly beside it. Brush piles shelter adjacent saplings, fence-line plants are protected, and established trees escape this extra pressure. Every predator in the modeled food web uses actual prey, including big cats, foxes, raptors, snakes, crocodiles, otters and predatory fish. Catches reduce prey populations and prey numbers limit predator capacity. Exposed prey are easier to catch; shrubs and tall groundcover reduce catches, while brush piles, logs and rocks give small prey additional refuge. A small refuge cannot hide a large grazer. Canopy helps against aerial hunters; logs, marsh edges and wooded banks shelter aquatic prey, and coral structure and seagrass provide reef cover. Failed hunts leave predators hungry and surviving prey flee toward a passable neighbouring tile, favouring cover. Adults without a meal for 30 game days cannot breed until they feed and have an extra monthly chance of moving away; dependent young are exempt from this additional food stress. Young trees and shrubs also lose growth in marginal dry sites, especially under established grass. Clear grass before planting, choose wetter sites and seasons, and mulch to reduce this extra establishment stress for 120 game days; protection can be renewed. The inspector, field guide and tool descriptions explain these pressures and countermeasures. These additions apply only to Challenging; existing Relaxed and Standard ecology stays unchanged.
- **Music** is a shuffled, crossfaded set of public-domain (CC0) lo-fi tracks by HoliznaCC0 in `assets/music/` (listed with their sources in `js/audio/tracks.js`). Nature sounds use licensed field recordings mixed with Web Audio. Each of the seven maps has its own mix, following local cover and water, nearby wildlife, weather, seasons and time of day.

## Maps

- **Hollis Farm** (Cascade foothills, Washington): 33 plants and 34 animals, salmon runs, beavers, winter floods and snow, summer fires. Has the eight-chapter campaign and Free Play.
- **Fazenda Esperança** (Pará, Brazil): an old cattle ranch where African pasture grass (braquiária) runs fence to fence and burns every dry season, with the rainforest waiting just beyond the north and east fences. 27 plants (cecropia, ingá, açaí and buriti palms, Brazil nut, kapok, ipê, heliconia, bamboo, and the invasive grasses) and 26 animals (jaguar, tapir, howler and spider monkeys, sloth, giant otter, toucan, scarlet macaw, harpy eagle, caiman, anaconda, pink river dolphin, arapaima and more). Sow the muvuca seed mix, shade out the grass, keep fire off the young forest, and reconnect the canopy so arboreal animals can move in through the treetops. Agoutis are the only animals that spread Brazil nuts. Has its own eight-chapter campaign (from pulling the first pasture grass to the jaguar's return) and Free Play with its own milestone goals.

- **Enkare Conservancy** (Serengeti, Tanzania): a communal grazing range where generations of too many cattle have left bare, crusted hardpan, gullies, famine weed (parthenium), prickly pear hedges and mesquite thickets, with a wire fence across the old migration route. 26 plants (dropseed, star grass, red oat grass, umbrella thorn, fever tree, baobab, sausage tree, candelabra euphorbia, aloe, and the invasives) and 26 animals (wildebeest and zebra that pass through with the dry-season migration, giraffe, elephant, black rhino, buffalo, hippo, lion, cheetah, leopard, hyena, ostrich, vultures, secretary bird, crowned crane, ground hornbill, Nile crocodile, dung beetles and more). Rip the hardpan and dig half-moon pits to catch the rain, sow soil builders, beat back the famine weed, and let red oat grass return once the soil has. Vultures and dung beetles only live here once there are herds to follow. It stays open savanna rather than turning to woodland: grass fires sweep through most dry seasons and kill saplings, thick grass starves woody seedlings of water, herds trample them, and grown trees keep their neighbours at a distance (only along the water do trees close up into a riverine strip). Each dry season the migrating wildebeest and zebra swim the river at the crossing in the middle of the map (crocodiles gather there while they cross) and pass on north to the park, which they only do once the north fence is down. Herds (wildebeest, zebra, gazelle, impala, buffalo, elephants, giraffe) move together behind a leader, and every animal walks or flies to water every few days to drink. Has its own eight-chapter campaign and Free Play.

- **Kebun Tualang** (North Sumatra, Indonesia; Free Play): an oil palm estate cut from lowland rainforest on the edge of the Leuser Ecosystem, handed back to be forest again. 29 plants (the oil palms themselves, acacia, mile-a-minute, Chinese violet, Siam weed, Koster's curse and alang-alang to beat; macaranga, terap, petai, durian, strangler fig, meranti, keruing, the tualang honey tree, jelutong and nibung palm; rattan, torch ginger, screw pine, pitcher plants and the corpse flower) and 35 animals (Sumatran orangutan, siamang, Thomas's langur, pig-tailed macaque, Sumatran tiger, clouded leopard, leopard cat, sun bear, Sumatran elephant and rhino, Malayan tapir, sambar, mouse-deer, wild boar, pangolin, palm civet, flying fox, rhinoceros hornbill, barn owl, Storm's stork, false gharial, arowana and more). The palms still bear fruit, and the village's monthly harvest pays for part of the work, so you grow forest between the rows first (*jangka benah*) and fell the palms as it closes over; palms shaded by young trees, and old palms, bear less. The southern half is peat drained by canals: drained peat dries out and burns in the dry season, so build canal blocks in a staircase up each canal until the peat is wet again (only then do peat swamp trees take, and the palms on it drown). An elephant fence closes off the old route from Leuser; barn owl boxes keep the plantation rats down. Free Play with its own milestone goals. and welcome screen show every map pinned on a world map (`js/ui/worldmap.js`, hand-traced coastlines). Each map keeps its own save. Choosing a different map reloads the page into it.

The vegetation renderer varies mature woodland height and foliage tone in stable patches, with mature crowns ten percent wider than their original proportions. The extra width eases in as trees grow; young saplings retain their growth scale. Existing clearings, plant identities and ecological canopy calculations stay unchanged. Palms, banana, baobabs and reef organisms keep their specialist proportions. Open `tools/vegetation-review.html?scene=groves` for a mixed woodland around a clearing. An optional ignored `tools/map-audit-output/groves-before/flora.js` snapshot enables comparison against the previous renderer on identical planted trees.

Regional vegetation palettes live in `js/render3d/palettes.js`: pine/sage/copper for the Northwest, oak/moss/rose for Atlanta, jade/fern/orchid for the Amazon, emerald/bronze for Sumatra, olive/straw/terracotta for the Serengeti, and sage/ochre/coral for Chinandega. Trees, understory, meadows and planted riverbank tufts are nudged toward coordinated greens and seasonal tones, about a third of the way, so each species keeps its own hue and relative lightness (fir, cedar and hemlock still read apart), as well as its flower colours and bloom timing. Meadow ground uses the same palette as its blades. Reef organism and substrate colours retain their existing treatment. The vegetation review displays palette swatches; `?scene=groves&palette=1` isolates the colour pass on identical models and planting using an optional ignored `tools/map-audit-output/palettes-before/flora.js` snapshot. Amazon and Sumatra forest scenes are available in the landscape selector.

Tree snow dusts whatever faces the sky, a little heavier up the crown than in its sheltered base. A deep snowpack loads every upward-facing branch but never the undersides, so crowns keep their shape and some green. Crown height is normalized separately for each species in both Full and Fast graphics, without changing growth or weather simulation. Other surfaces retain their upward-facing snow treatment. Open `tools/vegetation-review.html?scene=woodland&snow=1` to compare light and deep snow on identical trees, or use the Snow selector to inspect intermediate coverage.

Landscape lighting gives clear days a stronger sun-to-sky ratio, keeps shade slightly cooler under a high sun (golden hour and moonlight keep their full fill), and lets crowns and trunks receive branch and neighbouring-tree shadows in Full graphics. A faint sky-coloured veil separates scenery beyond the camera's focus, with slightly more haze in humid forests and overcast weather. Moonlight remains readable; rain and snow use a more diffuse light balance. Fast graphics retain the light balance and reduced haze without canopy shadow sampling. Reef lighting retains its underwater treatment. This uses existing materials and the existing shadow pass, with no added render passes. Open `tools/lighting-review.html` for identical landscapes under the previous and current lighting, including golden hour, moonlight, weather and graphics comparisons.

Inland shorelines have a patchy silt fringe with grass running down to the water in between, gravel pockets, scattered stones and occasional washed-up branches on wooded banks. Small bank-grass accents appear only where wetland groundcover actually grows, and follow its season. The details follow the rendered ground and water contours, refresh after planting or reshaping, and stay off roads, fields, trails and structures. They are decorative and do not add habitat resources. Fast graphics reduces gravel and grass across the whole shoreline; reef seabeds keep their existing look. Open `tools/riverbank-review.html` to compare Hollis Farm's creek, river and pond. Its optional before renderer lives in the ignored `tools/map-audit-output/riverbanks-before/terrain.js` snapshot. Run `node tools/riverbank-check.mjs` for alignment, editing, exclusions, world-state preservation and graphics checks across all seven maps.

Creek and river currents run downstream along the channel network: each connected stretch drains toward its lowest exit, so a creek flows into the river it joins and the river runs on past the mouth without an eddy. Inland water has lighter turquoise shallows, a soft broken highlight at the bank, faint drifting sky reflections and short wavelets at creek bends. Signed bed depth keeps the highlight on the ground/water contour, and shared flow samples soften tile seams. The details use the existing water mesh and noise texture, with no extra draw calls or render passes; Full and Fast graphics keep them. Open `tools/water-review.html` for still or animated creek, river and pond comparisons (the optional local before renderer is in ignored `tools/map-audit-output/water-before/terrain.js`). Run `node tools/water-check.mjs` for depth alignment, shared flow, bends, ponds and terrain-edit checks.

**Switched off for now** (`waterModel.enabled` in `js/sim/hollis-water.js`; add `?water=1` to the address to try it): Hollis plays with its original fixed ponds and beaver-dam flooding, and farms saved while it was briefly live load back to their underlying ground. When on, Hollis Farm has a limited gameplay water model: rain and snowmelt refill ponds, dry summer weather exposes muddy shallows while a pond's deep middle keeps about a quarter of its water, and shade slows evaporation. Newly dug ponds start full, and marsh stays marsh: it is saturated ground that follows its own slope rather than one pooled level. Beaver dams store creek water over connected low ground uphill; removing a dam lets its pool drain gradually. Prolonged inundation can turn trees into snags. Inspect explains these local changes. Reservoir storage uses the rendered ground triangles; underlying terrain, water volume and wet-day exposure survive save/load and landscape undo. Older Hollis saves initialize the new state from their current landscape. Other maps keep their existing hydrology. This is a small reservoir model with prescribed creek inflow and evaporation/seepage, not the lab's full grid flow or groundwater solver; regional flood events still use their existing rules. Open `tools/hollis-water-review.html` for the real-game terrain comparison, and run `node tools/hollis-water-check.mjs` for seasonal, dam, terrain, plant, budget, save and undo checks.

The experimental watershed lab at `tools/watershed-lab.html` demonstrates conservative surface flow, rainfall, soil infiltration and saturation, delayed groundwater return, evaporation, basin overflow and a manually placed dam. Its Amazon fixture contains an existing oxbow that reconnects under high water and isolates as water recedes. The lab has weather controls, stepping, flow and moisture views, cell inspection and a complete water budget. It runs separately from gameplay and saved farms. ## How the ecosystem works

The restored landscape is different on each map:

| Map | What a successful restoration should look like |
| --- | --- |
| Hollis Farm | Mixed Douglas-fir, cedar and hemlock forest with a fern understory, broadleaf trees along the creek, and open marshes. Meadows persist where you maintain them; unmanaged uplands eventually become forest. |
| Fazenda Esperança | Connected, evergreen rainforest with mixed crowns, palms and a shaded understory. Pasture grass retreats as the canopy closes. |
| Enkare Conservancy | Open grassland, green after rain and gold in the dry season, with scattered thorn trees and baobabs. Denser woodland stays close to water. |
| Magnolia Ridge | A lived-in neighborhood: houses and streets among native flower gardens, shade trees, wooded creek banks and rain gardens. Established native beds stay open. |
| Finca El Guanacaste | Dry forest on the volcano slopes, open cattle paddocks with scattered planted shade trees, living fences, streamside forest, coastal mangroves and a sandy turtle beach. Many dry-forest crowns lose their leaves in the dry season. |
| Kalinda Reef | A patchwork of hard and soft corals on stable substrate, seagrass and scattered giant clams on lagoon sand, open channels and a vegetated sand cay. Natural clam recruitment is slow and spaced out; existing adults and player planting retain their normal suitability. |
| Kebun Tualang | Mixed lowland rainforest and fruit gardens on mineral soil, with jelutong and nibung peat-swamp forest on rewetted peat. Peacock spikemoss covers the shady forest floor; corpse flowers spread slowly. Flooded swamp supports specialist trees; ordinary forest trees and oil palms struggle there. |

These targets combine each map's restoration story with regional habitat references: [Washington lowland forests (NPS)](https://www.nps.gov/mora/learn/nature/plants.htm), [Amazon canopy seasonality (NASA)](https://science.nasa.gov/earth/earth-observatory/defying-dry-amazon-greener-in-dry-season-than-wet/), [Georgia forest and wetland mosaics (USFWS)](https://www.fws.gov/refuge/piedmont), [Serengeti habitats (Tanzania National Parks)](https://tanzaniaparks.go.tz/serengeti/wildlife), [silvopasture in Nicaragua (FAO)](https://www.fao.org/docrep/013/i1881e/i1881e00.pdf), [Reef habitats (Reef Authority)](https://www.gbrmpa.gov.au/learn/coastal-ecosystems-great-barrier-reef), and [Leuser forest types (UNESCO)](https://www.unesco.org/en/mab/gunung-leuser?hub=66369). Garden and farming layouts are game-specific restoration choices, not claims that every regional ecosystem has that layout.

Between the population rules, animals lead visible daily lives (`js/sim/animal-life.js`). Cats stalk low and slow, then pounce; dogs and hyenas trot in and run prey down; snakes, crocodiles and monitors inch closer and strike; raptors circle and stoop. The target bolts a moment after the rush starts, and nearby animals the hunter would take scatter. Big kills leave a carcass where the prey fell: the hunter feeds, its pride or pack joins, and vultures, hyenas, coyotes and other scavengers come in. Prey stop and stare at a predator nearby, drift away from it, and bolt if it comes close. Fed predators lie up; hungry ones go looking for prey. Fire sends everything nearby running: animals flee the burning ground as a whole, avoid stepping through flames where they can, and birds lift out of the smoke; predators drop a hunt or a kill to go. On every map the land mammals (and cattle) walk to water every few days, the young play chase, and adults greet each other or, for horned and antlered rivals, spar. In the autumn rut (September to November) deer, elk and sambar stags seek each other out and fight bouts: they square up head to head, lock antlers and shove back and forth, break off and crash back in, and the loser gives ground. Elk also form harems in the rut: a bull gathers the cows nearby, keeps them close, leads them to water, drives back strays and bugles; bulls without cows shadow a harem from its edge, and one that beats the harem bull takes his cows. Carcasses provide a limited number of leftover meals, scaled to prey size; a pack member or scavenger claims one on arrival and satisfies its hunger. Fed animals leave remaining meals for others. Fleeing respects blocked diagonal corners, and danger escapes and feeding take priority over starting or joining a hunt. Run `node tools/animal-life-check.mjs` for rut, fire, escape barriers, shared meals, behavior priority and reef-swimming checks. Behavior choices use Math.random, and the catch is still decided once, on contact, with the same odds. Shared meals satisfy hunger like successful catches; habitat capacity retains its existing formula. The inspector shows what an animal is doing (stalking, chasing, feeding, drinking, on the alert, playing).

(Described for the Hollis farm; the Amazon and Serengeti maps run the same rules with their own species, seasons and climate.)

- **Time:** 1 game day per second at normal speed, 10 days a month, 120 days a year. Seasons change growth, moisture, blooming, fruiting and migration.
- **Plants** (33 PNW species) each have moisture, light and soil ranges. They grow where conditions suit them and decline where they don't. Once mature they spread seed. Seeds also drift in from the forest edges, from the river in floods, and (blackberry, broom, canarygrass) from the neighbouring farms.
- **Succession:** nitrogen fixers (red alder, lupine, Scotch broom) rebuild soil. Canopy shade shifts the understory to ferns and salal, and shade-tolerant cedar and hemlock replace short-lived alders. Dead trees become snags, then logs, then soil.
- **Water:** moisture falls off with distance from water. Creek shade sets water quality. Fish can only reach water that connects to the river, and the old culvert blocks it.
- **Wildlife** (34 species): each species rates every tile's habitat. Carrying capacity is the total suitable habitat divided by the home-range size, limited by needs across the whole property: prey for predators, snags for woodpeckers and bats, berries for bears, fish for otters and herons. Animals breed in season when there's room, die or leave when there isn't, and immigrate from their source edge. Deer and elk are blocked by the boundary fences.
- **Special behaviour:** beavers coppice willow, fell alder and build dams that flood new wetlands. Coho run up connected, shaded creeks each October, spawn, die and feed the soil, and their fry return three years later. Migratory birds leave in fall and come back if the habitat is still there.
- **Scale:** the farm is 120×90 tiles. Plants are smooth, instanced low-poly models that sway in the wind, with simpler versions used when zoomed out; animals and visitors use shared 3D model, scale and animation systems.
- **Terrain:** the valley slopes from the northern foothills down to the river. Hollows are wetter and ridges drier. Digging water carves the ground, and the Raise and Lower tools reshape it.
- **Snow:** Dec–Feb storms sometimes come in cold. A snowpack builds on snowy days, lingers on high open ground, stays thin under trees, and melts in rain and spring warmth.
- **Fire:** in late-summer droughts, lightning or a visitor's spark can start a wildfire. It spreads through dry grass, broom and blackberry, and runs uphill faster. Trails, water and bare ground stop it, and rain puts it out. Douglas-fir and oak usually survive; young trees and most shrubs don't, while native meadow plants resprout. Send a fire crew to fight it, or use controlled burns to cut the fuel ahead of time. Once every few years at most, a fire in a deep drought turns into a **crown fire** that burns through the forest canopy. It leaves standing snags, and fireweed, lupine and native grasses turn the burn into meadow until the forest returns.
- **Floods:** long winter rains push the river over low ground beside the river and creeks. Seedlings drown, fresh silt enriches the soil, floodplain seeds (willow, cottonwood, and canarygrass too) arrive, and beaver dams can wash out. Marshes and ponds absorb part of every flood.
- **Visitors:** build a trailhead parking lot beside a road and connect trails to it (within two tiles), with boardwalks over wetlands, viewing blinds and a visitor center. The rating depends on the wildlife seen from the trails, the scenery along them and their length. Visitors pay per head, trails cost upkeep, and people on the trails disturb shy species (elk, cougar, bear, heron, pond turtle) nearby.
- **Funding:** money is tight at first ($30,000). The land trust's monthly grant scales with the ecosystem health score and the number of species present, but only modestly; visitor donations become the main income once trails run through good habitat (Amazon eco-tourists give more per visit). Goals and chapters pay one-off grants (shown at the amount actually paid), and each new species a small discovery grant.
- **Wildlife pacing:** a species needs its habitat to stay suitable for months before it finds the farm, so returns spread out over years rather than arriving all at once. Difficulty sets how readily they come.

Vertical and crowded transfers retain the established trajectory; shallow leaps require a checked torso path and reachable landing bark.
