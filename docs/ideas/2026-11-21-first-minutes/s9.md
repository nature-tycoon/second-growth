# Session 9/10: Play the intro in the game

## Done

- **The film plays on a first visit** (`js/ui/intro.js`, wired in `js/main.js`). When there's no save, the map is PNW and this device hasn't seen the film, session 8's film plays over the loading screen while the game loads underneath. WebM is used where the browser plays it, MP4 otherwise. The overlay stays invisible and lets clicks through until the film is really playing, so a slow download leaves the loading screen showing. The game waits paused at the film's last view, with no opening, no prompts and no sound. The farm isn't drawn while the film covers it, so the video gets the machine. When the film ends and the game is ready, two frames of the farm are drawn and the film fades (0.9 s) into it at the same camera. Then one line, **"The forest stops at the fence. Bring it back."**, shows for about 3 s. After that the session 3 opening runs as before: the glide to the fence, the deer and the prompt.
- **Waiting and failure.** If the game is ready first, it waits for the film. If the film hasn't started by the time the game is ready (no network, no codec, an error), it is dropped without a word and the farm opens as it would have. If the film stalls for 6 s after the game is ready, it fades out where it is.
- **Skip at any moment**: the Skip button, Esc, or a tap or click anywhere. A skip before the game is ready shows the loading screen until it is. Keys, the wheel and pointers don't reach the game while the film is up, so the camera stays put.
- **Sound.** It tries to play with sound first (itch.io's "Run game" click may allow it). If the browser refuses, it plays muted with a clear "Sound on" button, which becomes "Sound off" while sound plays. The game's music and nature sound are held while the film plays (`music.hold`).
- **Events**: `intro_started { first, muted }`, `intro_skipped { second, first }`, `intro_finished { first }`, plus `intro_replay { from: 'start'|'menu', map }` (js/analytics.js). The film is created right after `initAnalytics()` so `intro_started` isn't lost.
- **Once per device**: `second-growth-intro-seen` in localStorage (try/catch). Without storage it doesn't play, so nobody sees it on every visit.
- **Watch intro** in the in-game Menu (next to "How to play") and in the start menu. The farm pauses underneath and gets its speed back after. From the start menu it returns to the start menu.
- **The returning player's start is trimmed** to a "Welcome back" menu: **Continue at <farm> (year N) →**, **New farm** (the full old chooser: map, mode, difficulty, sandbox, language, and Continue for other maps), **Watch intro**, **Settings** (which returns to the start menu). Nothing was removed. Like the old chooser it can't be dismissed into a farm nobody chose. With no save on the last map, the full chooser shows as before.
- **Phones upright.** The film plays upright, letterboxed (`object-fit: contain`), above the turn prompt. When it ends, the existing "Turn your phone sideways" prompt shows, now see-through so the farm the film ended on stays behind it. "Play upright anyway" works as before.
- **Automation.** The film is off under `navigator.webdriver` (every headless check, capture and film tool) unless the address has `?intro=1`, so none of the ~50 other browser checks changed. `?intro=0` turns it off for anyone. Save-Data connections skip it (5 MB).
- **Builds.** `assets/intro/` already ships in both: the itch workflow and `build-itch.sh` `git archive … assets …`, and `build-website.mjs` copies `assets` into `/play/`. The CSP already allows `media-src 'self'`. The check server now serves `.mp4`, `.webm` and `.jpg` with their types.

It plays the film at 8× (the check server can't seek). **Passes.**

## Open questions for Cole

1. **The line.** "The forest stops at the fence. Bring it back." I changed it from "The forest stops here" because the next prompt is about the fence, so the line hands over to it. *Recommendation:* keep it. Other options: "This was forest once. Bring it back." or "Thirty years from now, it could look like that."
2. **Watch intro on every map.** The film is of the PNW farm, but "Watch intro" shows on every map's menu. *Recommendation:* keep it everywhere. It's the game's intro, not the map's. Only a first visit to PNW plays it on its own, because only PNW's first view matches its last frame.
3. **A first visit through a `?map=` link (the website's landscape links) to another map gets no film.** *Recommendation:* fine for now. Those players chose a map on purpose. A per-map ending (the film, then a cut to that map's start) is the follow-up if the numbers show those players leaving too.
4. **The film costs a first visit 40 s before any play.** It's skippable from the first second, and the game loads underneath, so on a slow laptop (25–37 s loads) the wait is no longer. *Recommendation:* read `intro_skipped.second` and the 2-minute leave rate after a week, and if most skip within 10 s, cut it to the chase and the rewind (about 20 s).
5. **The turn prompt is now see-through everywhere**, not only after the film (the farm or loading screen shows dimly behind it). *Recommendation:* keep it. It reads as the game waiting rather than an error page.
6. **The returning menu's "New farm" replaces the save after a second click, as the old chooser did.** *Recommendation:* keep it. Nothing changed there, but it is now one step deeper.
