# S1: Worker backend

## Done
- `server/src/worker.js`: one plain-JS Cloudflare Worker. `POST /feedback` emails info@secondgrowth.earth through Resend (contact as Reply-To when it's an email; the game's snapshot fields listed as "Game details"), then stores the rating in D1. `POST /subscribe` adds the address to Kit (v4 API) and tags it by source. `GET /ratings` returns average, count and distribution, cached 10 minutes.
- Storage: D1 rather than KV, because a KV read-modify-write counter loses ratings when two arrive together and D1 is the same setup effort. Optional anonymous `player` id: a player's later rating replaces their earlier one.
- CORS for secondgrowth.earth (and www), nature-tycoon.github.io, html-classic.itch.zone, localhost/127.0.0.1:8347; POSTs with no or a foreign Origin get 403. Honeypot field `website`. 5 requests/minute per IP per endpoint via Cloudflare's rate-limit binding, with an in-memory fallback. Logs hold statuses and counts only.
- `server/wrangler.toml`, `server/schema.sql`; `wrangler deploy --dry-run` accepts the config and bindings (wrangler 4.162).
- `docs/backend-setup.md`: Cole's step-by-step (accounts, Resend DNS at Porkbun, Kit tags and key, D1, deploy, secrets, curl tests) and the contract for S2/S3 (shapes, honeypot, player id, CSP note, error table). Pointer line in AGENTS.md.
- `tools/backend-check.mjs` (joins the headless suite automatically): ~90 assertions with Resend, Kit and D1 mocked, including that no player text reaches the logs and that every error code and origin is in the doc. Verified it fails when the rate limit is changed.
