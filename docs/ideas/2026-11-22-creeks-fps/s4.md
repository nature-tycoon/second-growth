# Session 4: the meal shows through leaves while following a bird

## Done

- A held or eaten catch (`drawCatch` in `js/render3d/actors-common.js`: any animal with `a.prey` in `carry` or `feed`, including raptors, owls and snakes, with no species names) is now added as part of the tracked animal while its holder is followed or selected. The tracking lens (decision 0040) then draws it faintly through cover, the same way it draws the bird.
- `pose.meal` (the meal's centre and about half its length) is folded into the lens opening in `Renderer.updateFocus` (`js/render3d/scene.js`), so cover in front of the meal opens with the bird. The meal lies at the feet, mostly inside the bird's own box, so the opening grows only a little (bottom -0.189 → -0.193 for an owl holding a rabbit).
- No change when not following. While following a bird with a meal, the lens draws one more instance in its two passes. Otherwise nothing is added.
- Decision 0040 Rules has a new line, and the AGENTS.md index line is updated.
- Verified:
  - headless `impact.mjs --run` passes all 10 checks; `perf-guard-check` passes (one plant count fell, not from this change); `species-name-count` passes.
  - `lens-depth` and `canopy-reveal` browser checks pass.
  - visual-qa: a great horned owl eating a rabbit in a leafed-out pnw maple. `fauna.tracked` has 2 entries while it is selected and 0 when it is not. The meal's area changes 29–182 pixels between ghost on and off. The screenshot shows the owl and the rabbit faint through the leaves, not drawn whole over them.

## Open questions for Cole

1. A small catch (a vole in a hawk's feet) is only a few pixels even when it shows through the leaves. Should it be drawn bigger while you follow the bird? **Recommended: no.** It is drawn at its real size, at most 0.85× the bird, and enlarging it only while followed would make it pop in size when you start following.
2. Other held things (a primate's fruit, a beaver's branch) aren't drawn as separate objects today, so they need nothing. If a held item gets its own model later, should it show through cover the same way? **Recommended: yes.** Pass `tracked` to its `F.add` the way `drawCatch` does.

## New ideas noticed

- If a tracked animal and its meal ever came from the same species' pool (cannibalism, which no species does today), they would share one look-through copy and only one would show. Giving look-through.js one copy per tracked entry instead of one per pool would fix it. Not needed now.
- visual-qa suggested a regression check: a selected bird in `feed` with `a.prey` should give `fauna.tracked.length === 2` and `pose.meal.r > 0`. This could be added to `lens-depth-browser-check`. The harness from this session is in the scratchpad only (`meal.mjs`) and is not committed.
