Prototype scope & assumptions

This is a separate test landscape with no connection to saved farms. It models surface flow, basin storage, infiltration, soil saturation, a simple local groundwater reservoir, evaporation, plant water use and edge barriers. Every cell has a flat floor, shown in the view; flow moves across four neighboring edges. The small visible terrain steps are intentional.

Groundwater returns locally through a tunable linear reservoir; it does not yet flow laterally through an aquifer. Plant use is a fixed test demand, rather than actual vegetation. The dam is manually placed and has a fixed crest. The Amazon scene contains an existing oxbow with a raised entrance. Erosion, sediment transport, new oxbow formation, beaver construction, fish passage and integration with the game are subsequent stages.

Numerical checks: node tools/watershed-check.mjs. Design and integration notes: implementation plan.
