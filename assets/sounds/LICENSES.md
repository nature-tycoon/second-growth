Each listed audio file is distributed under its original license, including the same license for edited CC BY-SA clips. These sound asset licenses are separate from the game code license. The recordists do not endorse the game.

Edits: short excerpts, mono conversion, 32 kHz AAC encoding, high-pass filtering, loudness normalization, and short fades. Ambient loops overlap the end and beginning for a continuous seam. Exact offsets, source hashes and edits are recorded in `field-sources.json`.
